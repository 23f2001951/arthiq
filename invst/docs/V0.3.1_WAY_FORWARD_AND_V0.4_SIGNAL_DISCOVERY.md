The latest Arth IQ V0.3.1 diagnostic cycle materially improves the understanding of the predictive layer.

The central conclusion is no longer simply that **“the ML model is weak.”**

# 5. Cross-Sectional Quintile Evidence

Stocks were divided into five groups according to ML probability.

| Quintile | Mean Excess Return |
|---|---:|
| Q1 — Lowest ML probability | **+3.76%** |
| Q2 | +2.98% |
| Q3 | +2.57% |
| Q4 | +2.09% |
| Q5 — Highest ML probability | **+1.87%** |

The resulting spread is:

\[
Q5-Q1=-1.89\%
\]

The reported ordering is:

```text
Q1 > Q2 > Q3 > Q4 > Q5
```

This is a highly informative diagnostic.

The model is not simply producing random probabilities.

It is producing a ranking that is consistently opposite to the desired ranking.

# 6. Reverse-Signal Diagnostic

The explicit reverse test produced:

| Signal | Rank IC | IC IR | L/S Return |
|---|---:|---:|---:|

\[

This confirms that the model's ranking direction is systematically inverted in the current formulation.

However:

> **Do not immediately deploy 1-P.**

The reverse result is a diagnostic, not yet a production recommendation.

# 7. Why the Reverse Signal Requires More Investigation

There are at least two possible interpretations.

## Hypothesis A — Directional inversion

The model may have learned a genuinely useful relationship but the target interpretation is reversed.

## Hypothesis B — Contrarian / mean-reversion structure

The model may be learning that characteristics associated with high predicted probability are followed by weaker returns.

That could reflect:

- short-term momentum reversal
- valuation normalization
- risk premium effects
- sector effects
- regime effects
- feature interactions

Therefore the next experiment should explicitly distinguish these possibilities.

# 21. Statistical Significance Must Be Added

Current metrics include:

- IC
- IC IR
- L/S return
- quintile spread

The next diagnostic layer should add:

- t-statistics
- confidence intervals
- block bootstrap
- time-aware bootstrap
- permutation testing
- Newey-West adjusted inference where appropriate

For example:

```text
Q5-Q1 = +4.99%
```

is insufficient by itself.

You need to know whether the observed value is statistically distinguishable from zero.

---

# 22. Bootstrap Testing

Because financial observations are not independently distributed, ordinary IID assumptions can be misleading.

Use time-aware or block bootstrap methods.

The output should include something like:

```text
Observed Q5-Q1:
+4.99%

Bootstrap 95% CI:
[lower, upper]

Probability spread > 0:
XX%
```

The exact values must be generated from the actual dataset rather than assumed.

# 26. Change the Role of ML

The incorrect philosophy is:

> “ML decides what to buy.”

The preferred Arth IQ philosophy is:

> **“ML estimates incremental evidence around an existing investment thesis.”**

For example:

```text
Investment Score = 87
ML confidence   = 57%
Risk            = Low
```

The system should not automatically interpret this as a strong buy.

Instead:

```text
Strong fundamental thesis
+
weak ML confirmation
=
maintain core thesis
but avoid aggressive tilt
```

Conversely:

```text
Strong fundamental thesis
+
strong ML confirmation
+
favorable regime
+
low risk
=
high conviction
```

---

# 27. Separate Investment Thesis from Market Context

A better hierarchy is:

\[
\text{Investment Thesis}=f(\text{Fundamentals, Valuation, Growth})
\]

Then:

\[
\text{Market Context}=f(\text{Momentum, Regime, Sentiment})
\]

Then:

\[
\text{Risk Adjustment}=f(\text{Volatility, Drawdown, Liquidity})
\]

Finally:

\[
\text{Portfolio Conviction}
=
\text{Investment Thesis}
\times
\text{Market Context Adjustment}
\times
\text{Risk Adjustment}
\]

The exact mathematical implementation should be validated experimentally.

The important architectural principle is that these concepts should not be indiscriminately mixed into one opaque probability.

# 44. Bottom Line

The current Arth IQ evidence supports four strong conclusions:

### 1. The full 24-feature ML model should be rejected.

It produces a systematically inverted ranking and negative out-of-sample evidence.

### 2. The exact Platt + 50/50 + γ=0.50 configuration should be rejected.

It does not outperform the deterministic baseline.

### 3. Fundamentals-only deserves serious investigation.

It is currently the strongest predictive candidate:

```text
Rank IC       +0.0179
IC IR         +0.07
Positive IC   60%
L/S return    +4.99%
```

but it remains **unvalidated** at institutional scale.

### 4. Arth IQ should become a hierarchical investment-decision system.

The future architecture should separate:

```text
Investment Thesis
+
Market Context
+
Predictive Evidence
+
Risk
+
Portfolio Construction
```

rather than forcing everything into one opaque classifier.
