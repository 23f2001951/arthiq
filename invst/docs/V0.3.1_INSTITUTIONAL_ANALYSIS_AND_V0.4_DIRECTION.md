## Executive Summary

### Overall verdict

**Research quality: 8.5/10**

The V0.3.1 work is strong from a quantitative-research and engineering-discipline perspective, but the predictive ML layer has **not yet demonstrated robust out-of-sample alpha**.

# 1. The Most Important Discovery

The apparent improvement from the ML blend does **not** survive the untouched 2024–2026 test period.

The aggregate development/validation results showed:

| Model | CAGR | Alpha | Sharpe | Max Drawdown |
|---|---:|---:|---:|---:|
| Deterministic | 4.60% | -2.56% | -0.17 | -38.49% |
| ML only | 4.40% | -2.75% | -0.19 | -39.01% |
| 70/30 | 4.79% | -2.37% | -0.15 | -39.47% |
| **50/50** | **4.92%** | **-2.23%** | **-0.14** | **-36.28%** |
| 30/70 | 4.65% | -2.51% | -0.16 | -39.62% |

The 50/50 blend therefore looks strongest in the aggregate development/validation experiment.

However, strict nested testing tells a different story:

| Period | Baseline CAGR | ML γ=0.50 | Delta |
|---|---:|---:|---:|
| Development 2016–2020 | 8.34% | **8.96%** | **+0.62%** |
| Validation 2021–2023 | 0.25% | **1.32%** | **+1.07%** |
| **Untouched Test 2024–2026** | **-0.02%** | **-1.27%** | **-1.25%** |

The pattern is:

```text
Development
      ↓
ML wins

Validation
      ↓
ML wins

Untouched Test
      ↓
ML loses
```

Therefore:

> **The current ML formulation is not robust enough to be considered production alpha.**

The correct research conclusion is not that ML has failed permanently. It is that the current hypothesis has **not generalized**.

# 5. The Probability Distribution Is a Major Weakness

```text
Min       0.141
Q1        0.483
Median    0.494
Q3        0.510
Max       0.849

IQR       0.027
Std       0.082
```

The important observation is:

> **Median = 0.494**

and:

> **IQR = 0.027**

This means much of the cross-section is compressed around 50%.

Conceptually:

```text
Stock A   49.1%
Stock B   49.7%
Stock C   50.2%
Stock D   50.5%
Stock E   51.0%
```

Those probabilities do not provide enough separation for a portfolio optimizer to treat them as strong conviction differences.

Therefore:

> **The model currently lacks strong cross-sectional discrimination.**

This is one reason why calibration improvements do not automatically translate into investment usefulness.

\[

\]

This asks:

That is a difficult prediction problem.

The outcome may depend heavily on:

- earnings announcements
- sector rotation
- market regime
- valuation regime
- macro shocks
- corporate events
- liquidity
- market risk appetite

The current feature set may not contain enough forward-looking information to predict this target reliably.

Therefore:

# 9. The Target Should Be Expanded in V0.4

Test several alternative targets.

## Target A — 90D market-relative return

\[
R_{excess,90D} = R_{stock,90D} - R_{NIFTY500,90D}
\]

## Target B — Risk-adjusted excess return

\[
R^{riskadj}_{90D} = \frac{R_{stock,90D}-R_{NIFTY500,90D}}{\sigma_{90D}}
\]

## Target C — Sector-relative excess return

\[
R_{sector,90D} = R_{stock,90D} - R_{sector,90D}
\]

## Target D — Ranking objective

Rather than asking:

```text
Winner / Loser
```

ask:

> **Can the model correctly rank the top stocks versus the bottom stocks?**

This is potentially more aligned with portfolio construction.
