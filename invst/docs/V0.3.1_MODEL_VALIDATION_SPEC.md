### Diagnostic 1: Probability Calibration & Reliability
- **Hypothesis**: The ML classifier may output poorly calibrated probabilities that distort portfolio weights.
- **Formulation**:
  - Compare **Raw Model**, **Platt Scaling** (Logistic Sigmoid), and **Isotonic Regression**.
  - **Brier Score**: $BS = \frac{1}{N}\sum_{i=1}^N (p_i - y_i)^2 \le 0.22$
  - **Expected Calibration Error (ECE)** across $M=10$ equal-frequency bins:
    $$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
  - **Log Loss**: $-\frac{1}{N} \sum [y_i \ln p_i + (1 - y_i)\ln(1 - p_i)]$
  - **Reliability Curve**: Plot empirical frequency $\bar{y}_m$ vs mean predicted confidence $\bar{p}_m$.
- **Class Balance**: Explicitly report class balance $\mathbb{P}(y=1)$ vs $\mathbb{P}(y=0)$.

### Diagnostic 2: ML Probability Distribution Audit
- **Hypothesis**: The cross-sectional distribution of $p_i$ is either clustered tightly around 0.50 (low signal resolution) or exhibits high variance with extreme tail values that destabilize portfolio sizing.
- **Metrics per Quarter**: Min, 25th percentile (Q1), Median, 75th percentile (Q3), Max, Interquartile Range (IQR), and Standard Deviation.

### Diagnostic 3: Gamma Sensitivity Ladder
- **Hypothesis**: The conviction exponent $\gamma=1.0$ is excessively aggressive, amplifying estimation noise. Milder exponents ($\gamma \in [0.25, 0.50]$) may harvest outperformance conviction without triggering concentration drag.
- **Evaluation Ladder**: Test $\gamma \in \{0.00, 0.25, 0.50, 0.75, 1.00, 1.50, 2.00\}$:
  - $\gamma = 0.00 \implies$ Pure Deterministic HRP ($m_i = 1.0$)
  - $\gamma = 0.50 \implies$ Square-root dampening ($m_i = \sqrt{p_i / 0.50}$)
  - $\gamma = 1.00 \implies$ Linear conviction ($m_i = p_i / 0.50$)
  - $\gamma = 2.00 \implies$ Quadratic conviction ($m_i = (p_i / 0.50)^2$)
- **Performance Matrix**: CAGR, Active Alpha, Sharpe, Sortino, Calmar, Max Drawdown, Volatility, Upside Capture, Downside Capture.
- **Institutional Finding**: Baseline MDD is **-38.49%** vs $\gamma=0.50$ MDD of **-39.01%**. $\gamma=0.50$ reduces the drawdown amplification observed at more aggressive tilts ($\gamma=1.00$ was -42.17%, $\gamma=1.50$ was -43.85%), but does **not** improve maximum drawdown versus the deterministic baseline.

### Diagnostic 4: Pure ML Ranking & Information Coefficient (IC) Test
- **Hypothesis**: Decoupling the ML predictive signal from HRP reveals whether the ML model generates raw predictive alpha independently of portfolio construction.
- **Information Coefficient (Pearson IC)**:
  $$\text{IC}_t = \rho\left(\hat{\mathbf{p}}_t, \mathbf{R}^{\text{excess}}_{t \rightarrow t+90}\right)$$
- **Spearman Rank Information Coefficient (Rank IC)**:
  $$\text{Rank IC}_t = \rho_s\left(\text{rank}(\hat{\mathbf{p}}_t), \text{rank}(\mathbf{R}^{\text{excess}}_{t \rightarrow t+90})\right)$$
- **Long-Short Spread (Top 20% vs Bottom 20%)**:
  $$R^{\text{LS}}_t = \bar{R}_{t \rightarrow t+90}(\text{Top } 20\%) - \bar{R}_{t \rightarrow t+90}(\text{Bottom } 20\%)$$
- **Summary Metrics**: Mean IC, IC Standard Deviation, IC Information Ratio ($\text{IC IR} = \frac{\mu_{\text{IC}}}{\sigma_{\text{IC}}}$), % Positive Quarters, Annualized Long-Short Return, Long-Short Sharpe.

### Diagnostic 5: Deterministic vs ML Standalone Comparison
- **Hypothesis**: Compare whether the deterministic `Investment Score` possesses higher forward predictive power than the ML probability.
- **Evaluation**: Side-by-side comparison of IC, Rank IC, and Long-Short spread for:
  - Factor A: Pure V0.2.1 Investment Score
  - Factor B: Pure V0.3 ML Outperformance Probability

### Diagnostic 6: Deterministic + ML Score Blending & Configuration Disambiguation
- **Hypothesis**: Blending fundamental conviction with statistical probability yields superior risk-adjusted alpha over either factor alone.
- **Model Blends**:
  - Model A: 100% Investment Score (0% ML)
  - Model B: 100% ML Probability (0% Investment Score)
  - Model C: 70% Investment Score + 30% ML Probability
  - Model D: 50% Investment Score + 50% ML Probability (Achieved 4.92% CAGR in aggregate dev/val backtest)
  - Model E: 30% Investment Score + 70% ML Probability
- **Configuration Disambiguation**: The gamma sweep evaluated pure ML multiplier scaling ($\gamma=0.50$ achieved 4.40% CAGR), while the blend experiment evaluated score blending (Model D 50/50 achieved 4.92% CAGR). The combined configuration (**Platt + 50/50 Blend + $\gamma=0.50$**) must be explicitly backtested under identical PIT constraints before designating any production default.

### Diagnostic 7: Feature Importance & Redundancy Ablation
- **Hypothesis**: High collinearity between raw factors and derived Arth IQ scores dilutes model coefficients.
- **Ablation Feature Sets**:
  - **Set 1 (Raw Fundamentals & Risk)**: 18 raw features (excluding derived scores).
  - **Set 2 (Arth IQ Derived Scores)**: 4 scores (`composite`, `investment`, `business`, `growth`).
  - **Set 3 (Combined Feature Matrix)**: All 22 base + 2 interaction features.
- **Feature Significance**: Permutation importance / logistic regression standardized weights and stability across walk-forward folds.

### Diagnostic 8: Feature Timestamp & Zero-Lookahead Audit
- **Hypothesis**: Absolute invariant verification that no look-ahead bias contaminates feature inputs or labels.
- **Assertions**:
  - For every rebalance date $t$: all input dates $t_{\text{price}} \le t$, $t_{\text{filing\_published}} \le t$, $t_{\text{news}} \le t$.
  - Forward label window $(t, t+90]$ strictly post-dates rebalance decision timestamp.

### Diagnostic 9: Multi-Horizon Prediction Analysis
- **Hypothesis**: Forward alpha may be stronger at longer fundamental horizons (180D, 252D) than quarterly trading horizons (30D, 90D).
- **Target Horizons**: 30 days (1 month), 60 days (2 months), 90 days (1 quarter), 180 days (half-year), 252 days (1 year).
- **Metrics**: IC, Rank IC, Long-Short return, and Brier score across horizons.

### Diagnostic 10: Regime-Conditioned Signal Analysis
- **Hypothesis**: The ML model was designed to eliminate HRP's cyclical drag during bull markets and high volatility expansions.
- **Conditioning Regimes**:
  - **Market Trend**: Bull Regime ($R_{\text{Nifty500}, 90d} > 0$) vs Bear Regime ($R_{\text{Nifty500}, 90d} \le 0$).
  - **Volatility State**: High VIX ($\text{India VIX} > 18$) vs Low VIX ($\text{India VIX} \le 18$).
- **Institutional Finding**: In the current sample, **High VIX (>18)** had **0 quarters** while Low VIX had 25 quarters. Claims regarding high-volatility ML performance are inconclusive and require a revised regime definition or longer historical window.
- **Metrics by Regime**: IC, Rank IC, Hit Rate, and Active Alpha.

  - **Empirical Backtest Note**: Current backtests execute against the core 20-stock representative universe. Full 500-stock 10-year empirical evaluation is pending ingestion of complete historical NSE daily bhavcopy and corporate disclosure filings.

### Diagnostic 12: Strict Nested Out-of-Sample Protocol

## 5. Architectural Philosophy & V0.4 Bridge

Arth IQ adheres to the **Confidence Layer Architecture**:

```
                       FUNDAMENTAL VALUATION ENGINE
                                    │
                                    ▼
                         BUSINESS QUALITY & MOAT
                                    │
                                    ▼
                        RISK & BALANCE SHEET HEALTH
                                    │
                                    ▼
                          DETERMINISTIC SCORE
                                    │
                                    ▼
                            ML CONVICTION LAYER
                     "How confident is the evidence?"
                                    │
                                    ▼
                         HRP PORTFOLIO ALLOCATION
                                    │
                                    ▼
                          ARTH IQ RECOMMENDATION
```

The ML model does **not** replace fundamental valuation or risk constraints. It acts as an out-of-sample conviction layer that scales exposure based on empirical cross-sectional evidence.

### 5.1 The Normalized Additive Decision Function
To preserve interpretability and prevent runaway multiplicative tilts, Arth IQ V0.4 adopts a normalized additive scoring framework:

$$\boxed{\text{ArthScore}_i = w_F F_i + w_M M_i + w_E E_i + w_R R_i + w_H H_i}$$

Where:
- $F_i$ = Fundamental conviction (Quality + Moat + Solvency) $\in [0, 100]$
- $M_i$ = ML directional conviction $\in [0, 100]$
- $E_i$ = Expected excess return / alpha magnitude
- $R_i$ = Risk-adjusted edge ($\mathbb{E}[R_{\text{excess}}] / \sigma_{\text{downside}}$)
- $H_i$ = Horizon fit (30D, 90D, 1Y, 3Y, 5Y)
- Normalized weights: $w_F + w_M + w_E + w_R + w_H = 1.0$

### 5.2 The Confidence Formulation
Confidence is mathematically modeled as cross-pillar consensus rather than model margin alone:
$$\text{Confidence}_i = f\left(\text{Calibration Quality}, \text{Fundamental Score}, \text{Regime Agreement}, \text{Data Quality}\right)$$
- **High Conviction Tilt:** When ML, Fundamentals, and Regime align with low calibration error.
- **Neutral HRP Anchor:** When ML disagrees or regime is adverse, default to fundamental HRP without penalty.

### 5.3 Controlled Feature-Group Ablation Protocol (Immediate Research Priority)
Before training any new models or adding complex indicators, Arth IQ must isolate the exact origin of the negative Rank IC (-0.0909) via 8 controlled subsets:
- **Set A:** Fundamentals only (`roe_5yr`, `roce_5yr`, `debt_equity`)
- **Set B:** Valuation only (`pe_ttm`, `pb`, `ev_ebitda`)
- **Set C:** Risk only (`annualised_vol`, `beta`, `max_drawdown`, `downside_semivariance`)

- **Set E:** Fundamentals + Valuation
- **Set F:** Fundamentals + Risk
- **Set G:** Fundamentals + Valuation + Risk
- **Set H:** Full 24-feature combined matrix
- **Diagnostic Inversion Test:** Evaluate $P_{\text{reverse}} = 1 - P$ to determine whether the model systematically learned an inverted relationship.
